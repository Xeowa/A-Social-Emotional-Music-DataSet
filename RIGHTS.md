# Rights and License Scope

This document clarifies which materials are covered by the repository's CC BY-NC 4.0 license and which materials require separate review.

| Material | Rights holder or source | Repository license scope |
| --- | --- | --- |
| README and repository documentation authored by Xeowa | Xeowa | CC BY-NC 4.0 |
| Original dataset metadata and annotations authored by Xeowa | Xeowa | CC BY-NC 4.0 |
| Repository organization and original descriptive text | Xeowa | CC BY-NC 4.0 |
| Musical compositions | Respective rightsholders | Excluded unless separately identified as licensed |
| Performances | Respective performers/rightsholders | Excluded unless separately identified as licensed |
| Sound recordings | Respective recording rightsholders | Excluded unless separately identified as licensed |

## Practical requirements

- Access to the audio dataset does not by itself grant permission to republish every underlying work.
- Users must review the source and applicable permissions for each recording before redistribution or public deployment.
- Derived metadata or models should document the dataset version and any preprocessing, exclusions, or relabeling.
- A material is covered by CC BY-NC 4.0 only when Xeowa owns it and it is identified above as included, or when a file explicitly states that coverage.

The full CC BY-NC 4.0 legal text remains in the repository's `LICENSE` file. This scope statement supplements that file; it does not replace the license or expand it to third-party material.
